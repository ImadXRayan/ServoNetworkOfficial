# Glossary

**Auto-release** — Application authorization to settle an eligible delivered order after a configured waiting period.

**Buyer** — The user purchasing a service and funding an order.

**Chain ID** — Numeric identifier for a blockchain network; Polygon Mainnet is `137`.

**Deal** — The escrow contract’s record of buyer, provider, token, amount, and settlement state for an order.

**Escrow** — An arrangement that holds funds until defined release or refund conditions are met.

**EVM** — Ethereum Virtual Machine, the execution environment used by Polygon and other compatible networks.

**Gas** — Blockchain transaction fee paid in the network’s native asset.

**KYC** — Know Your Customer identity verification. Servo’s reviewed implementation integrates Didit with configurable feature gates.

**Nonce** — A single-use value that prevents replay of a signed authorization.

**PolygonScan** — A public blockchain explorer for inspecting Polygon addresses, transactions, events, and verified source.

**Provider / seller** — The user offering and delivering a service.

**Reconciliation** — Comparing application records with blockchain state, receipts, and events to repair missed confirmations safely.

**RLS** — Row Level Security, database rules restricting which records a user may access or change.

**SVO** — Servo Coin, the platform’s Polygon ERC-20 utility token.

**Treasury** — The configured recipient of escrow release fees and a defined token allocation role.

**Voucher** — A backend signature authorizing a specific caller, order list, nonce, action, vault, and chain to settle already funded escrow deals.
