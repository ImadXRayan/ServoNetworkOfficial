# Contributing

This public repository is intended for product and protocol documentation. It must not contain private application source, credentials, user data, internal operational procedures, or unpublished security details.

## Proposing a change

1. Open an issue describing the inaccurate or missing information.
2. Cite a public contract, transaction, released product behavior, or maintainer-approved source.
3. Keep claims precise and distinguish current behavior from roadmap plans.
4. Update navigation links when adding, moving, or renaming a document.
5. Check every relative Markdown link and every blockchain address.
6. Request maintainer and security review for changes involving contracts, funds, authentication, KYC, disputes, or legal claims.

## Documentation rules

- Never guess an address, number, date, partner, audit, listing, or regulatory status.
- Use **TODO** for missing work and **Unverified** for claims awaiting evidence.
- Do not describe roadmap features in the present tense.
- Do not claim “trustless,” “immutable,” “fully decentralized,” “audited,” or “guaranteed” without carefully stating the relevant boundaries.
- Avoid price predictions and investment language.
- Prefer plain English and define unavoidable blockchain terminology.

## Local review

Confirm that `README.md` links to every public document and that all internal links resolve. Review rendered Markdown for headings, tables, mobile readability, spelling, and accidental disclosure before any commit or publication.
